# Gaming-Dependency-Pack

Contains all commonly required redistributable packs for VC, .Net, DX, and OpenAL
Installs everything clearly and quick with a self-elevating batch file.

Also opts out of various MSFT and other common telemetry APIs using documented envvars.

Created because I wanted games and apps to work right after reinstalling.
Open an issue if you have a request.


Versions are numbered as such:
v(YY).(MM).(revision)
